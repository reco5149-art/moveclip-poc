# 문제 정의서

## 내 도메인에서 AI로 개선할 지점: 운동 코칭 영상 → SNS 콘텐츠 자동화

| 항목 | 내용 |
|---|---|
| 작성자 | Kim |
| 작성일 | 2026-09-22 |
| 프로젝트명 | **MoveClip** — 코칭 영상에서 숏츠·카드뉴스를 자동으로 뽑아내는 AI 파이프라인 |
| 활용 기술 | 포즈 추정(YOLO11-pose), 신호처리 기반 반복 검출, 음성인식(Whisper/ONNX), 자동 리프레이밍, 텍스트→이미지 렌더링 |

---

## 1. 도메인 설명

### 1-1. 내가 일하는 영역

> 나는 움직임의 원리와 퍼포먼스를 연구해 현장에 적용하고,
> 사람들이 운동·스포츠·일상의 라이프스킬 속에서 건강과 신체 기능 향상을 체득하도록 만드는 사람이다.

이 정의 아래 실제로 다루는 현장은 네 갈래다.

| 현장 | 하는 일 | 영상이 나오는 방식 |
|---|---|---|
| 크로스핏 / 하이록스 | 그룹 클래스 지도, WOD 코칭 | 수업 중 고정 카메라 롱테이크 |
| 기능성 운동 / 골프 피트니스 | 1:1 PT, 동작 진단과 교정 | 회원 동작 촬영 + 내 시연 |
| 통증케어 / 마사지 | 세션 진행, 셀프케어 안내 | 기법 시연 클로즈업 |
| 온라인 (인스타그램) | 위 세 가지를 콘텐츠로 발행 | **위 촬영본을 편집해서 사용** |

### 1-2. 이 문제 정의서가 다루는 지점

앞의 세 현장은 "오프라인에서 잘한다"가 이미 되어 있다. 문제는 **네 번째 줄, 오프라인의 결과물이 온라인으로 넘어가는 구간**에서 생긴다. 촬영은 계속 쌓이는데 발행은 안 된다. 즉 이 문서가 정의하는 문제는 *운동 지도 자체*가 아니라, **운동 지도의 산출물을 콘텐츠로 변환하는 공정**이다.

## 2. 현재의 문제 (AS-IS)

### 2-1. 지금의 작업 순서

```
[1] 촬영          수업·세션 중 고정 카메라로 10~40분 롱테이크 1개
      ↓
[2] 탐색  ★병목   전체를 스크러빙하며 "쓸 만한 구간" 찾기
      ↓
[3] 컷 편집       반복 동작의 시작/끝 지점을 눈으로 찾아 자르기
      ↓
[4] 세로 변환     16:9 → 9:16 크롭. 사람이 프레임 밖으로 나가면 수동 키프레임
      ↓
[5] 자막          내가 말한 내용을 직접 듣고 타이핑
      ↓
[6] 카드뉴스      별도 앱에서 문구 다시 쓰고 디자인 (사실상 처음부터 다시)
```

### 2-2. 무엇이 번거로운가 — 병목 3가지

**① 탐색 병목 (가장 큼)**
30분짜리 영상에서 쓸 만한 30초 구간 3개를 찾는 일. 실제 편집 시간보다 **찾는 시간이 더 길다.** 영상은 대부분 "세팅·설명·쉬는 시간"이고, 진짜 쓸 구간은 동작이 일어나는 몇 분뿐인데, 그 위치는 타임라인만 봐서는 알 수 없다.

**② 반복 노동 병목**
컷 → 크롭 → 자막의 세 단계는 콘텐츠 1개마다 똑같이 반복된다. 창의적 판단이 들어가는 구간이 아닌데도 시간은 가장 많이 먹는다. 편집 실력이 늘어도 총량은 줄지 않는다.

**③ 재활용 병목**
같은 촬영본이 릴스 1개로만 소비되고 끝난다. 그 안에서 내가 말한 코칭 큐("무릎 방향 보세요", "여기서 호흡 뱉고") 자체가 카드뉴스·블로그의 원재료인데, 텍스트로 남아있지 않으니 재활용할 방법이 없다.

### 2-3. 그 결과

- 발행 목표는 **주 3회**인데 실제로는 **주 0.5~1회**에 그친다.
- 촬영본만 쌓이고 "언젠가 편집할 폴더"가 계속 커진다.
- 편집이 밀리면 발행 간격이 벌어지고, 인스타 계정 성장(= 수익화)의 전제가 무너진다.

> ※ 본 문서의 AS-IS 수치는 현재 내 체감 기준 추정치다. PoC 검증 단계에서 **동일 영상 1개를 수동으로 편집하며 실측한 값으로 교체**한다. (→ 5-3 측정 프로토콜)

## 3. 개선 가설

### 3-1. 핵심 가설

> **"AI가 편집을 대신한다"가 아니라, "AI가 편집할 대상을 찾아준다."**

편집의 미적 판단은 내가 하는 게 맞다. 하지만 **"어디를 봐야 하는지 찾는 일"과 "찾은 걸 규격에 맞게 자르고 붙이는 일"은 기계가 더 잘한다.** 운동 영상은 이 자동화에 유리한 성질이 하나 있다 — **동작이 주기적으로 반복된다.** 반복(rep)은 관절 각도의 주기 신호로 나타나므로, 사람이 눈으로 찾던 "세트의 시작과 끝"을 신호에서 기계적으로 뽑아낼 수 있다.

### 3-2. AI를 어느 단계에 넣는가

| 단계 | 넣는 기술 | 하는 일 | 대체하는 수작업 |
|---|---|---|---|
| **A. 자세 추출** | YOLO11-pose (포즈 추정) | 프레임마다 17개 관절 좌표 추출 → 시계열 생성 | — (새로 생기는 입력) |
| **B. 반복·세트 검출** | 관절각 주기 신호 분석 | 무릎/고관절 각도의 극값에서 rep을 세고, rep이 몰린 구간을 1세트로 묶음 | **[2] 탐색** |
| **C. 하이라이트 점수화** | 동작 강도 + 발화 밀도 결합 | 세트별 점수를 매겨 상위 N개를 숏츠 후보로 제시 | **[2] 탐색** |
| **D. 자동 리프레이밍** | 키포인트 중심 추적 + 스무딩 | 사람 중심을 따라가며 9:16으로 크롭, 떨림 제거 | **[4] 세로 변환** |
| **E. 자막 생성** | 음성인식 (Whisper ONNX) | 발화를 타임스탬프와 함께 텍스트화 → SRT 생성·번인 | **[5] 자막** |
| **F. 카드뉴스 생성** | 발화 텍스트 요약 + 이미지 렌더링 | 코칭 큐를 뽑아 인스타 1:1 카드 이미지로 렌더링 | **[6] 카드뉴스** |

### 3-3. 기대하는 변화 (TO-BE)

```
[1] 촬영 (동일)
      ↓
[2~6] 영상 업로드 → AI 자동 처리 (수 분)
      ↓
[검토] 제시된 숏츠 후보 3~5개 중 쓸 것 고르기        ← 사람이 하는 일은 여기만
      ↓
[다듬기] 자막 오탈자 수정, 카드뉴스 문구 톤 조정
```

**사람의 역할이 "찾기 + 만들기"에서 "고르기 + 다듬기"로 바뀐다.** 이게 이 프로젝트가 증명하려는 한 문장이다.

## 4. 대상 사용자

| 순위 | 대상 | 이들이 받는 도움 |
|---|---|---|
| **1차** | **나 자신** | 편집 병목이 풀려 발행 주기가 유지된다. 인스타 성장의 전제 조건이 확보된다. |
| **2차** | 1인 운영 트레이너·치료사 | 편집자를 고용할 수 없어서 콘텐츠를 포기한 사람들. 도메인 지식은 있는데 편집 시간이 없다는 조건이 나와 완전히 같다. |
| **3차** | 소규모 체육관·스튜디오 | 수업 영상 1개에서 회원 공유용 클립을 자동 추출. 별도 촬영 없이 콘텐츠가 나온다. |

**대상이 아닌 사람:** 전담 편집자가 있는 팀, 스튜디오 조명·다중 카메라로 기획 촬영하는 브랜드. 이들은 이미 병목이 없다.

## 5. 성공 기준

### 5-1. 정량 지표

| # | 지표 | AS-IS (추정) | PoC 목표 | 측정 방법 |
|---|---|---|---|---|
| 1 | **숏츠 후보 도출 시간** (영상 1개당) | 20~30분 | **3분 이내** (AI 처리시간 포함) | 업로드~후보 제시까지 스톱워치 |
| 2 | **반복(rep) 카운팅 정확도** | — | 수동 카운트 대비 **오차 ±1회 이내가 80% 이상** | 세트별 육안 카운트와 대조 |
| 3 | **세트 구간 검출 재현율** | — | 육안 라벨 대비 **recall ≥ 0.8** | 내가 라벨링한 정답 구간과 IoU 비교 |
| 4 | **자막 수정률** | 100% (전부 타이핑) | 수정 필요 문장 **20% 이하** | 생성 자막 대비 수정한 문장 수 |
| 5 | **1회 처리 산출물** | 릴스 1개 | **숏츠 3개 + 카드뉴스 1세트** | 결과 파일 개수 |
| 6 | **주간 발행량** (도입 4주 후) | 0.5~1회 | **주 3회** | 실제 게시물 수 |

### 5-2. 정성 기준 (합격선)

- [ ] 영상을 올리면 **사람 손이 닿지 않고** 숏츠 후보가 나온다 (완전 자동 실행)
- [ ] 제시된 후보 중 **최소 1개는 수정 없이 그대로 올릴 만하다**
- [ ] 리프레이밍된 세로 영상에서 **사람이 프레임 밖으로 나가지 않는다**
- [ ] 카드뉴스 문구가 **내가 실제로 한 말에서 나온다** (일반론이 아니라)

### 5-3. 측정 프로토콜

1. 실제 촬영본 1개(10분 이상)를 정한다.
2. **수동 기준선 측정** — 평소 방식대로 숏츠 3개를 만들며 단계별 소요 시간을 기록한다. 이 값이 AS-IS 실측치가 된다.
3. 같은 영상으로 PoC를 돌리고 지표 1~5를 측정한다.
4. 정답 라벨(세트 구간, rep 수)은 내가 직접 영상을 보며 만든다.

### 5-4. 실패로 간주하는 경우

- 반복 검출이 빗나가 **후보를 일일이 다시 찾아야 한다면** → 탐색 병목이 그대로이므로 실패
- 자동 크롭 결과를 **매번 손으로 고쳐야 한다면** → 수작업 총량이 줄지 않았으므로 실패

## 8. 왜 이게 나에게 중요한가

내 성장 카드 ①번 항목은 **"인스타 계정 키우기(수익화) — 카드뉴스 자동화, 숏츠 제작, 운동·마사지 영상 제작"** 이었다. 그동안 이걸 *"편집을 더 열심히 배우자"* 로 해석해왔는데, 실제 병목을 분해해보니 **편집 실력의 문제가 아니라 탐색·반복 노동의 문제**였다. 실력이 늘어도 시간은 줄지 않는 구조다.

이 PoC는 그 구조를 바꾸는 시도다. 성공하면 콘텐츠 발행이 "시간이 나면 하는 일"에서 **"촬영하면 자동으로 따라오는 일"** 이 된다.
